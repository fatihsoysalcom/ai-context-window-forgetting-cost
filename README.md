# AI Context Window Forgetting Cost

This Python script simulates an Artificial Intelligence (AI) system with a limited "context window" or memory. It demonstrates how an AI can "forget" previously provided information when new data pushes older context out, leading to a "re-learning cost" for the user. The example tracks how many times the user has to re-state information that the AI has forgotten.

## Language

`python`

## How to Run

Save the code as `ai_forgetfulness.py`. Open a terminal or command prompt, navigate to the directory where you saved the file, and run `python ai_forgetfulness.py`.
